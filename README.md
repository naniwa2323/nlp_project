# nlp_project

## データファイル

データセットは、記事単位で学習用80%・テスト用20%に分割しています。
乱数シードは `42` に固定し、`isfake` のクラス比率を保つように層化分割しています。

同じ記事から作成したチャンクが、学習用とテスト用の両方に含まれないように、記事の分割後にチャンクを作成しています。

| ファイル名 | 内容 |
|---|---|
| `train_articles.csv` | 学習用の記事データ。元データの本文・ラベル・文字数情報などを保持 |
| `test_articles.csv` | テスト用の記事データ。元データの本文・ラベル・文字数情報などを保持 |
| `train_chunks.csv` | 学習用記事から作成した100文字のチャンクと、人間／AIの正解ラベル |
| `test_chunks.csv` | テスト用記事から作成した100文字のチャンクと、人間／AIの正解ラベル |

### 記事CSVの列

1行が1件の記事に対応します。
本文は変更せず、元データの列を保持しています。

| 列名 | 内容 |
|---|---|
| `id` | 記事ID |
| `context` | 記事の本文全体 |
| `isfake` | 記事の種類。`0`：人間のみ、`1`：人間＋AI、`2`：AIのみ |
| `nchar_real` | 人間が書いた部分の文字数。混在記事ではAI生成部分の開始位置 |
| `ncahr_fake` | AIが生成した部分の文字数。列名は元データの表記を保持 |

### チャンクCSVの列

チャンクは、記事から切り出した100文字のテキストです。
1行が1個のチャンクに対応します。

| 列名 | 内容 |
|---|---|
| `id` | チャンクの元となる記事ID |
| `chunk_index` | 記事内のチャンク番号。0から開始し、除外されたチャンクの番号は欠番 |
| `start_char` | 元の本文における開始位置。0から数え、この位置の文字を含む |
| `end_char` | 元の本文における終了位置。この位置の文字は含まない |
| `text` | 切り出した100文字の本文 |
| `label` | チャンクの正解ラベル。`0`：人間、`1`：AI |

例えば、`start_char = 50`、`end_char = 150` の場合、
Pythonの `context[50:150]` に相当し、元の本文の51〜150文字目を表します。

### チャンクの作成方法

- チャンクサイズ：100文字
- ストライド：50文字
- 本文の正規化や空白の削除は行わず、元の文字位置を保持
- 完全な100文字のチャンクのみを使用

開始位置を50文字ずつずらすため、隣り合うチャンクは50文字分が重なります。
文や改行の区切りに関係なく、文字数に基づいて切り出します。

| チャンク番号 | `start_char` | `end_char` | 本文中の範囲 |
|---|---|---|---|
| 0 | 0 | 100 | 1〜100文字目 |
| 1 | 50 | 150 | 51〜150文字目 |
| 2 | 100 | 200 | 101〜200文字目 |

100文字未満の記事は記事CSVに保持されますが、チャンクは作成されません。
また、各開始位置から記事末尾までが100文字に満たない場合、そのチャンクは作成しません。

### チャンクのラベル付け

ラベルは元データの `isfake` と `nchar_real` から自動的に付与し、
手動ラベリングは行っていません。

| 元の記事の `isfake` | チャンクのラベル |
|---|---|
| `0`：人間のみ | すべて `0`（人間） |
| `1`：人間＋AI | `nchar_real` を境界とし、人間部分は `0`、AI部分は `1` |
| `2`：AIのみ | すべて `1`（AI） |

混在記事（`isfake = 1`）では、次の条件で判定します。

- `end_char <= nchar_real`：人間のチャンク（`label = 0`）
- `start_char >= nchar_real`：AIのチャンク（`label = 1`）
- `start_char < nchar_real < end_char`：境界をまたぐため除外

境界をまたぐチャンクは、学習用・テスト用の両方のチャンクCSVから除外しています。
元の記事本文は、記事CSVにそのまま保持しています。
